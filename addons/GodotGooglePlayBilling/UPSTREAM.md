# First-party Google Play Billing plugin

Vendored unmodified from the official Godot SDK integrations release 3.3.0 (2026-07-27), Google Play Billing Library 9.1.0. MIT license in LICENSE.

- Source: https://github.com/godot-sdk-integrations/godot-google-play-billing
- Release: https://github.com/godot-sdk-integrations/godot-google-play-billing/releases/tag/3.3.0
- Official installation/API: https://godot-sdk-integrations.github.io/godot-google-play-billing/
- Release ZIP SHA-256: `20d75623d6f337f08d8283c83098b73678d5f575e39247af5a8eb80588b18568`

The plugin is enabled in project.godot. Android export requires an installed Android build template and Gradle build. No Android export or billing connection is claimed by enabling this editor plugin. The game adapter is scripts/play_billing.gd; paid entitlements are granted and consumed/acknowledged only by the authenticated backend after Google verification. Desktop and browser builds cannot initiate Google Play purchases.
